# Changelog

## v1.0.0 (2026-11-17)

First public release.

- Home: PC health score, processor, memory and storage gauges in plain English, actionable suggestions.
- Apps: processes grouped by app with icons, live memory/CPU and trends; Close or Force quit with protection for critical Windows processes.
- Storage: drive/folder scanner with a treemap colored by file type, biggest-files list, delete to Recycle Bin with Undo.
- Quick clean: temp files, browser caches, crash reports, thumbnail cache, old installers, Recycle Bin.
- Activity: live CPU (per core), memory, disk and network graphs.
- Remote access: HTTPS + pairing code, view-only mode, QR code, `--serve` headless mode.
- Light/dark themes, Ctrl+K command palette, phone layout, audit log.
